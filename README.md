# PHP-галерея з lightGallery

Невеликий сайт-галерея на чистому PHP і MySQL: статті з категоріями, сторінка перегляду, пошук і перегляд зображень через lightGallery. Проєкт 2023–2024. Історію відновлено приблизно: оригінальні дати файлів не збереглися.

Зроблено за відеоуроком про галерею на PHP, далі переписано й доповнено під власні потреби: шаблонізатор на `render()`, вибірки з бази, динамічна галерея lightGallery за кнопкою.

## Як влаштовано

- `index.php` — точка входу: читає статті й категорії, збирає сторінку з шаблонів `templates/*.tpl.php` через функцію `render()`.
- `functions.php` — вибірки з MySQL (`get_statti`, `get_text`, `get_cat`) і рендер шаблонів.
- `view_text.php` — сторінка однієї статті та обробка пошуку.
- `templates/` — головний шаблон, меню категорій, список статей, шаблон галереї; `templates/js/script.js` — ініціалізація lightGallery.
- `config.php` — параметри підключення до бази (значення замінено заглушками `YOUR_DB_*`), назва сайту, кількість записів на сторінку.
- `schema.sql` — структура таблиць `category`, `menu`, `statti`.

## Запуск

PHP 5 з розширенням `mysql` (застарілі функції `mysql_*`) і MySQL. Створіть базу за `schema.sql`, впишіть доступи в `config.php`. Сторонні файли до репозиторію не входять, покладіть їх самі: jQuery 1.11.2 у `templates/js/`, lightGallery 1.1.4 (`templates/js/lightGallery.js`, `css/lightGallery.css`, шрифти в `fonts/`), стилі jQuery UI у `css/`, зображення в `img/` і мініатюри в `img/th/`.
